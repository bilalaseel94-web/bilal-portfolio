# كيف يعمل هذا المشروع؟

الموقع هو النتيجة التي يراها الزائر. هذا المستودع يحتوي الملفات التي تصنع الموقع ويسجّل التعديلات عليها.

1. **HTML:** المحتوى والعناوين والأقسام.
2. **CSS:** الألوان والتصميم وترتيب الصفحة على الهاتف.
3. **JavaScript:** الأزرار والتبويبات التفاعلية.
4. **Python:** تجهيز النسختين العربية والسويدية وفحص ملفات النشر.
5. **GitHub:** حفظ التعديلات وتشغيل الفحوص.
6. **Cloudflare Pages:** عرض الموقع للزوار باتصال HTTPS. عند تفعيل صلاحية النشر، ترسل GitHub Actions الملفات إليه بعد نجاح الفحص.

التحديث التلقائي يعني أن التعديل المعتمد على الفرع الرئيسي يستطيع الوصول إلى الموقع دون رفعه يدويًا. نراجع التغييرات أولًا؛ الأتمتة لا تقرر ماذا يُكتب عنك.

- **Commit:** حفظ تعديل مع وصفه.
- **Pull request:** عرض تعديل للمراجعة قبل اعتماده.
- **Deployment:** نشر نسخة من الموقع.

تساعد النسخ المحفوظة على معرفة ما تغيّر والرجوع عن تعديل محدد.

تم التنفيذ بمساعدة الذكاء الاصطناعي. دور بلال الموثّق هو تحديد المتطلبات ومراجعة المحتوى والتصميم وطلب التحسينات. استخدام أدوات المشروع لا يعني وحده إتقان البرمجة أو إدارة النشر بشكل مستقل.
