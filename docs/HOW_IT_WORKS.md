# The project in plain language

The website is the finished result. This repository contains its source files and the history of changes.

1. HTML tells the browser what content to show.
2. CSS controls the layout, colours and mobile presentation.
3. JavaScript makes the tabs and disclosures respond to visitors.
4. Python prepares the Swedish and Arabic pages and checks the public files.
5. GitHub stores reviewed changes and runs checks.
6. When publishing access is enabled, GitHub Actions sends the checked files to Cloudflare Pages, which serves the website over HTTPS.

Automatic publication means a checked change on `main` can update the website. It does not mean AI independently decides what to write. Changes should be reviewed first.

Useful terms: a **commit** is a saved change; a **pull request** is a proposed change for review; a **deployment** is a published version. Keeping versions makes it possible to inspect or reverse a specific change.
